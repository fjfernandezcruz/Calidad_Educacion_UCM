# Calidad de la Educación UCM

Prototipo web independiente para hacer más clara y accesible la consulta de los recursos de calidad de la Facultad de Educación - Centro de Formación del Profesorado de la Universidad Complutense de Madrid.

## Ver el prototipo

Abre `index.html` directamente en un navegador o inicia un servidor local desde esta carpeta:

```powershell
python -m http.server 8000
```

Después visita `http://localhost:8000`.

El prototipo utiliza HTML, CSS y JavaScript nativos, sin dependencias ni proceso de compilación. Los enlaces a documentos, servicios y páginas institucionales apuntan a sus destinos publicados por la UCM.
